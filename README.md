# Project: Task Manager Web App
This task manager web app is a simple, intuitive, and minimalist approach to organizing a to-do list.

https://curious-longma-ed2-ethanm.netlify.app/

## Features

- Create tasks
- View tasks
- Mark tasks complete
- Delete tasks

## Tech Stack

- React
- Vite
- Supabase Database
- Netlify Hosting

## Setup

Install dependencies:

npm install

Run locally:

npm run dev
